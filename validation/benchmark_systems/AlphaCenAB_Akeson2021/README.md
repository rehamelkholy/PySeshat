# alpha Cen AB real-data benchmark (Akeson et al. 2021)

Data: VizieR catalogue J/AJ/162/14 (Akeson et al. 2021, AJ 162, 14; bibcode 2021AJ....162...14A):
`table6.dat` (relative astrometry), `table7.dat` (HARPS radial velocities), `ReadMe`.

These files are **not redistributed** with PySeshat (journal copyright and CDS terms).
Download them from the VizieR/CDS archive
(https://vizier.cds.unistra.fr/viz-bin/VizieR?-source=J/AJ/162/14, "ReadMe+ftp")
into this folder, then run `python scripts/alpha_cen_real_data.py`.

If you use these data, cite Akeson et al. (2021) and acknowledge VizieR: "This research has
made use of the VizieR catalogue access tool, CDS, Strasbourg, France (DOI: 10.26093/cds/vizier).
The original description of the VizieR service was published in Ochsenbein et al. (2000, A&AS 143, 23)."
