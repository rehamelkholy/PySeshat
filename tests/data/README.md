# Test data

`sun_reference_stis_001.fits` — CALSPEC observed solar reference spectrum
(file header SOURCE: "Bohlin, Dickinson, & Calzetti 2001, AJ, in prep."), flux
at 1 AU. Used by `tests/test_synthetic_photometry_sun_calibration.py` to test
the zero-point chain independently of model atmospheres. Source: STScI
CALSPEC database; this copy was taken unchanged from the `pyphot` 2.1.1
distribution (`pyphot/libs/`).
