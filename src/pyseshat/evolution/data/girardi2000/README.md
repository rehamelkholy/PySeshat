# Girardi et al. (2000) evolutionary tracks and isochrones

`mstracks.tsv` and `isochrones.tsv` are the VizieR tables `mstracks` and
`isochron` of catalogue J/A+AS/141/371 (Girardi, Bressan, Bertelli & Chiosi
2000, A&AS, 141, 371), exported in ASU-TSV format on 2026-08-29 (the full
request is recorded in each file header). They are redistributed unchanged
under the CDS/VizieR licence
(<https://cds.unistra.fr/vizier-org/licences_vizier.html>).

`pyseshat.evolution.grids.load_default_evolution_model()` loads them by
default. Please cite Girardi et al. (2000) when using them, and acknowledge
VizieR: "This research has made use of the VizieR catalogue access tool, CDS,
Strasbourg, France (DOI: 10.26093/cds/vizier). The original description of
the VizieR service was published in Ochsenbein et al. (2000, A&AS 143, 23)."
